## 2026-10-21

### Context
Netlify 24h telemetry and a local load test showed avoidable function/bandwidth
usage: RSC `?_rsc=` requests ~79K, `/sitemap.xml` 1.1K requests / 73.84 MB,
`/login` 6.3K requests, and several prerendered pages still invoking functions
on almost every hit. Goal: keep repeat/crawler traffic off functions without
blocking legitimate SEO or users.

### Completed
- **Static/ISR route split** (removed `searchParams` from page 1):
  - `app/blog/page.tsx` (page 1) + `app/blog/page/[page]/page.tsx`,
    `app/blog/category/[category]/page.tsx` and
    `app/blog/category/[category]/page/[page]/page.tsx`.
  - `app/events/page.tsx` (page 1) + `app/events/status/[status]/page.tsx`.
  - `app/category/[category]/[city]/page.tsx` (page 1) +
    `app/category/[category]/[city]/page/[page]/page.tsx`.
  - Views extracted to `components/blog/BlogListView.tsx`,
    `components/events/EventsListView.tsx`,
    `components/category/CategoryCityArtistsView.tsx`.
  - `lib/seo/slugs.ts`: added `blogPagePath()`, `eventStatusPath()`.
  - Filters/pagination now use canonical paths. Legacy `?page=` / `?category=` /
    `?status=` URLs render page 1 (no redirect) — documented tradeoff.
- **CDN caching**: `next.config.ts` `PUBLIC_PAGE_CACHE_SOURCES` emits
  `Netlify-CDN-Cache-Control: public, s-maxage=3600, stale-while-revalidate=86400`
  for public pages, static auth pages, robots, manifest and sitemaps. Admin,
  API, search and tokenized ticket routes stay uncached.
- **Images**: new `lib/utils/imagekit.ts` (`ikUrl`) applies ImageKit `tr=`
  transforms in `ArtistCard`, `HeroSection`, `HomeBackground` (preload capped
  at 3), `MagicBento`, `EventCard`, `EventHero` and blog covers.
  Dev benchmark: homepage images 909 KB -> 77 KB.
- **RSC payload**: `getRandomArtists()` now `$project`s only rendered fields and
  `$slice`s `media.images` to 1 after `$sample`. Home cache key bumped to `:v2`
  so stale full documents are not served.
- **Redis / rate limits**: Redis REST fetch no longer forces `cache: "no-store"`
  (would opt pages into dynamic rendering). Public GETs `/api/search` and
  `/api/artists` use new `rateLimitLocal()` (per-instance) so Upstash commands
  stay reserved for writes/auth; write routes keep the distributed limiter.
- **Fonts/bundles**: `display: "swap"` on all fonts, no preload for Limelight /
  JetBrains Mono; `PlasmaWave` lazy via `dynamic()`; `MagicBento` is client-only
  dynamic. `SessionProvider` no longer refetches on window focus.
- **Prefetch**: `prefetch={false}` on navbar, footer, home cards and
  artist/blog/event cards + pagination to cut `?_rsc=` function invocations.
- **Bots**: `app/robots.ts` disallows `AhrefsBot`, `SemrushBot`, `MJ12bot`,
  `Amzn-SearchBot`, `meta-externalagent` (in addition to existing AI bots).
- **OG images**: `/og` now sends 1-year immutable cache headers, caps input
  lengths, allowlists remote image hosts (SSRF/error hardening), pre-validates
  images with a 4s timeout, and no longer self-fetches the logo. Fallback image
  is cached 5 minutes.
- **Docs/rules**: `AGENTS.md` now states the owner runs `npm run build` manually.
