## 2026-10-21 — Cloudflare cache / 503 investigation

### Context
Production Cloudflare telemetry showed ~42.35K requests, ~40.06K origin
requests, an **8.35% cache hit rate**, ~37.02K Dynamic requests, 602 HTTP 503s,
10 HTTP 500s, and zero edge rate-limit actions. Netlify showed high `Age` on
HTML while Cloudflare showed `DYNAMIC`, so the cache layer and origin headers
were audited on branch `investigate/cloudflare-cache-503`.

### Completed
- **Cache classification**: new `lib/cache/publicRoutes.ts`; public informational,
  artist, city, category, blog and event routes are shared-cacheable.
  `/login`, `/register`, `/reset-password`, `/profile`, `/switch-account`,
  `/search*`, `/admin*`, `/api*` and `/my-ticket*` are private.
- **Origin headers**: `next.config.ts` now sends
  `Cache-Control: public,max-age=0,s-maxage=3600,stale-while-revalidate=86400`
  plus the Netlify CDN header for public HTML. Private pages send
  `private,no-store` and `no-store` CDN directives. Cloudflare still needs a
  Cache Rule for extensionless HTML.
- **Public assets**: `netlify.toml` adds 7-day image/icon headers and 1-year
  immutable font headers, because the Next regex does not reach `public/`.
- **RSC safety**: audit confirmed `text/x-component` on RSC requests; manual
  Cloudflare bypass expressions cover `rsc`, prefetch headers, `_rsc`, and
  `Accept: text/x-component`.
- **Reliability**: Mongo selection/connect timeouts capped at 5 s and rejected
  connection promises reset; `clientIp()` now prefers `cf-connecting-ip`.
- **OG**: standard `s-maxage`/`CDN-Cache-Control` and `X-Robots-Tag: noindex`;
  `/og` kept crawlable for social previews but sends `X-Robots-Tag: noindex`.
- **Diagnostics**: `scripts/audit-cloudflare.mjs`, `scripts/test-cache-policy.mjs`,
  `scripts/test-redis.mjs`; npm scripts `audit:cloudflare`, `test`, `test:cache`,
  `test:redis`.
- **Docs**: `docs/CLOUDFLARE_CACHE_503_AUDIT.md` with RCA, baseline, manual
  Cloudflare rules, verification and rollback.

### Verification
- `npx tsc --noEmit`: passes.
- `npm test`: 7/7 cache-policy tests pass.
- `npm run test:redis`: Upstash REST `PING`, `SET`, `GET`, `INCR`, `EXPIRE NX`,
  bounded `TTL` pass.
- Pre-deploy audit: 14 public pages lack `s-maxage`, 5 auth pages advertise
  shared caching, no Cloudflare HTML HIT, and RSC advertises shared caching.
  These are expected before the branch is deployed and are the post-deploy
  acceptance checks.
