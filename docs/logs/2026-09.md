## 2026-09-12 (OTP spam + Mongo pool)

### Completed
- OTP spam mitigation: SMTP mails now multipart (text+HTML) with `replyTo`,
  plain subjects ("Your BlueEye verification code" / "Your BlueEye password
  reset code"); login/verify/reset UI tells users to check spam/promotions.
- MongoDB M0 connection fix: capped per-process pool (`maxPoolSize: 10`,
  `minPoolSize: 0`, `maxIdleTimeMS: 30s`, overridable via
  `MONGODB_MAX_POOL_SIZE`). Root cause: uncapped default pool (100) x 11
  `next build` workers x 5454 static pages spiked Atlas to ~440/500.
